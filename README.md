# 📱 PhonePe Payment Insights Dashboard (PowerBI)

Ye project ek interactive **PowerBI Dashboard** hai jo PhonePe ke payment transactions aur user insights ko visualize karta hai. Iska maqsad digital payment trends, user behavior aur financial metrics ko asani se samajhna hai.

## 📊 Key Metrics & Features
- **Total Transactions:** Tracked total volume (e.g., 300K+ transactions).
- **Total Value:** Total transaction value of ₹3.47bn+.
- **User Demographics:** Analysis based on age segment distribution and user activity.
- **Trend Analysis:** Transactions over time and patterns between weekdays vs. weekends.
- **Service Breakdown:** Insights into various service transaction values (Money Transfer, Insurance, Loans, Recharge, etc.).

## 🛠️ Tools & Technologies Used
- **Microsoft PowerBI:** For dashboard creation and interactive visualizations.
- **DAX (Data Analysis Expressions):** For calculated measures and metrics.
- **Excel:** For dataset storage and management.

## 📂 Repository Files
- `Phonepay PowerBI Dashboard.pbix`: Main PowerBI report file.
- `Phonepe-Final-Dataset.xlsx`: Dataset file used for the analysis.
- `Screenshots/`: Visual previews of the dashboard pages.
